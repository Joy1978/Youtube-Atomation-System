# Privacy Policy

Last updated: 2026-09-03

This is a personal, non-commercial automation project ("AI News Shorts") that generates and publishes YouTube Shorts on a schedule.

## What this app accesses

This app requests the following Google OAuth scopes, used only for its own automation, run by and for the repository owner:

- **YouTube Data API v3 (youtube.upload)** — used solely to upload video files this pipeline generates to the owner's own YouTube channel.
- **Google Sheets API (spreadsheets)** — used solely to write a log row (title, date, video status) to the owner's own private Google Sheet, for tracking upload history.

## What this app does not do

- It does not access, read, or collect data belonging to any other Google user or channel.
- It does not sell, share, or transmit any Google user data to third parties.
- It does not use any data for advertising or profiling.
- No end users interact with this app directly — it is a single-owner automation tool.

## Data retention

Generated video files and logs are stored only in the owner's own GitHub repository and Google account. No data is stored on third-party servers beyond GitHub Actions' temporary build environment, which is discarded after each run.
